# Путь Маугли — сайт для GitHub Pages

Статическая база знаний клуба менторов: девять шагов менти и девять ходов ментора, 35 инструментов, архетипы наставников и благодарности авторам. Сборка не нужна: это готовые HTML, CSS, JS и изображения.

## Быстрый старт

1. Создайте публичный репозиторий, например `mowgli-path`.
2. Загрузите **содержимое** этой папки в корень репозитория: `index.html`, `src/`, `assets/`, `.nojekyll`, README и `.github/`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Source: Deploy from a branch**.
5. Укажите ветку `main` и папку `/ (root)`, сохраните.
6. Через 1–2 минуты сайт откроется по адресу `https://<username>.github.io/<repo>/`.

## Вариант с GitHub Actions

1. Загрузите файлы так же, включая `.github/workflows/pages.yml`.
2. В **Settings → Pages → Source** выберите **GitHub Actions**.
3. Каждый пуш в `main` будет публиковать сайт заново. Прогресс — во вкладке **Actions**.

## Что внутри

- `index.html` — оболочка сайта и метаданные.
- `src/data.js`, `src/tools-a.js`, `src/tools-b.js` — тексты: кейсы, инструменты, авторы, архетипы.
- `src/views.js`, `src/views2.js` — разметка страниц.
- `src/app.js` — маршруты, поиск, фильтры, печать.
- `src/styles.css`, `src/pages.css`, `src/extra.css` — оформление.
- `assets/` — обложка, девять иллюстраций кейсов и четыре портрета архетипов.
- `.nojekyll` — отключает обработку Jekyll, чтобы GitHub отдавал файлы как есть.

## Обновление

- Кейс — `src/data.js`, массив `cases`.
- Инструмент — `src/tools-a.js` или `src/tools-b.js`.
- Стили — `src/styles.css`, `src/pages.css`, `src/extra.css`.
- Картинка — положите файл в `assets/` и поправьте CSS-класс `.tile--cXX`, `.case-hero--cXX` или `.arch--...`.

После правок ничего собирать не нужно: закоммитьте и запушьте.

## Локальный просмотр

Из этой папки:

```bash
python -m http.server 8000
```

и откройте `http://localhost:8000`. Можно открыть и `index.html` напрямую — внешних запросов и сборки нет.

## Особенности

- Навигация использует хеш-маршруты (`#/path`, `#/tools`, `#/case/c06`). Они работают на GitHub Pages без настройки сервера. Прямые адреса без `#` (например, `/tools`) GitHub Pages не знает.
- Репозиторий и сайт публичны; не добавляйте персональные данные.
- Бесплатный GitHub Pages: сайт до 1 ГБ и мягкий лимит 100 ГБ трафика в месяц. Текущий размер — около 2 МБ.
