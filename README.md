# Путь Маугли 2 — версия для менторской встречи

Один файл `index.html`: стили, скрипты и все изображения внутри. Ничего не нужно собирать и подключать — достаточно положить файл в корень репозитория.

**Версия:** 26 ноября 2026. Это отдельная версия: первая (`put-maugli.html`) не изменялась.

## Что добавлено по сравнению с первой версией

1. **Карточка для встречи в каждом кейсе.** Что может происходить, что не стоит делать, как попробовать, готовая фраза, ещё два инструмента и кто поделился опытом. Карточка стоит сразу после заголовка кейса — её удобно открывать во время разговора.
2. **Развилка менторской позиции.** «В этой истории ментору важно…» — четыре «не» и строка про баланс.
3. **Слой «Попробуй на ближайшей встрече» в каждом из 35 инструментов.** Одно действие сейчас, вопрос для встречи и чек-лист из трёх пунктов.
4. **Благодарности как эмоциональный центр.** Вместо справочника — история каждого автора: что он оставил в клубе, какие инструменты за ним стоят, благодарность ведущего. На каждой карточке две кнопки: скопировать карточку текстом и скачать её картинкой PNG 1080×1080 (квадрат для поста в соцсетях), с подписями «Роль», «Прямая речь», «Инструменты», «Благодарность».
5. **Блок «Что мы поняли» в конце благодарностей** — семь выводов клуба после историй авторов и авторской позиции. Черновик коллективной позиции, который стоит сверить с участниками.
6. **Авторская позиция внизу главной.** Прямая речь автора проекта о том, как собирался клуб.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий.
2. Загрузите в **корень** три файла: `index.html`, `.nojekyll`, `README.md`.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
4. Ветка `main`, папка `/ (root)`, **Save**.
5. Через 1–2 минуты: `https://<username>.github.io/<repo>/`.

Скрытый `.nojekyll` при перетаскивании файлов часто не загружается. Если его нет — **Add file → Create new file**, имя `.nojekyll`, пустое содержимое.

## Если страница не открывается

| Что видно | Причина | Что сделать |
|---|---|---|
| 404 | Файлы во вложенной папке, а не в корне | В корне должен быть именно `index.html` |
| «There isn't a GitHub Pages site here» | Pages не включён или идёт первая сборка | Подождите 2 минуты, обновите Settings → Pages |
| Ошибка про ветку | Ветка называется `master` | Укажите реальную ветку |

## Навигация

Хеш-маршруты: `#/path`, `#/tools`, `#/tool/<id>`, `#/case/c06`, `#/archetypes`, `#/about`, `#/authors`. Работают на Pages без настройки сервера.

## Правки

Исходники — в папке `mowgli-kb-v2/`:

- тексты кейсов и карточек — `src/v2-cases.js`;
- слой «Попробуй сейчас» — `src/v2-tools.js`;
- истории и благодарности авторов — `src/v2-authors.js`;
- семь выводов — `src/v2-manifest.js`;
- разметка — `src/views.js`, `src/views2.js`, стили — `src/*.css`.

После правок пересоберите файл:

```
multitool-node --skill websites site.cjs bundle "mowgli-kb-v2/index.html" "put-maugli-v2.html"
multitool-node --skill websites site.cjs check "put-maugli-v2.html"
```

и замените `index.html` в репозитории.

## Ограничения

- Раздел «Что мы поняли» — синтез ведущего, а не утверждения от имени клуба: формулировки требуют сверки с участниками.
- Копирование карточки работает, если браузер разрешает доступ к буферу; иначе используйте скачивание файла.
- Сайт публичный: персональных данных, кроме имён участников клуба, в нём нет.
